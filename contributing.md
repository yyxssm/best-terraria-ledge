## 📋 What "Multi-Cheat" Means Here

The term covers a lot of different things, so here is what this package actually
is and is not.

**What it is**

A single build containing several independent modules that can each be enabled or
disabled, sharing one configuration system, one updater and one menu.

**What it is not**

- Not a subscription. No account, no login, no recurring payment.
- Not an installer. Nothing is written outside its own folder.
- Not a ban reset. If the title bans by hardware, that is a separate module with
  its own requirements and its own limits.
- Not a guarantee. Modules are updated against current builds, not against future
  ones.

**The module list, honestly**

| **Module** | **Present** | **Default** |
| --- | --- | --- |
| Overlay | yes | off |
| Assist | yes | off |
| Cosmetic | yes | off |
| Utility / presets | yes | on |
| Updater | yes | on |

**Why everything defaults to off**

Because a build that does something on first launch is a build you cannot
evaluate. Starting from nothing means every change you observe is one you made.

**What to expect from updates**

The updater checks on launch and pulls a new build when one exists. If a module
stops working after a game patch, that is the normal state of affairs — re-run
the updater before assuming anything is broken.
